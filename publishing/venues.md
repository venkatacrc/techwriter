# Venues

Where work on GPUs, training, inference, reinforcement learning, systems and their mathematics is published. Deadlines, page limits and policies change every year: **always read the current call for papers and author guidelines**. This file deliberately gives no dates.

Choose a venue by its readers first: who do you want to read the work, and where do they read?

## Conferences: machine learning systems, architecture, high-performance computing

| Venue | Readers and fit |
|---|---|
| MLSys | ML systems: training and inference systems, compilers, kernels, hardware for ML |
| ASPLOS | Architecture, programming languages and operating systems together; accelerators, compilers |
| ISCA, MICRO, HPCA | Computer architecture; GPU and accelerator microarchitecture |
| SC (Supercomputing) | High-performance computing; large-scale training, communication, performance analysis |
| PPoPP | Parallel programming: GPU algorithms, concurrency, performance |
| CGO | Code generation and optimisation; compilers such as Triton and those built on Multi-Level Intermediate Representation (MLIR) |

## Practitioner venues

- **ACM Queue**: practitioners writing for practitioners; peer-reviewed articles on practice.
- **Company and lab engineering blogs**: often the highest-readership venue for systems work.
- **arXiv**: not a venue but a preprint server; see `process.md`.
- **Workshops at systems conferences** (for example, workshops on ML systems co-located with ASPLOS, ISCA or MLSys): fast feedback on early work.

## Choosing

1. Find five papers you would cite, and note where they appeared. Your readers are there.
2. Read three papers from the last edition of the venue: is your contribution the kind they publish?
3. Match the evidence bar: architecture venues expect simulation or hardware evidence; systems venues expect a real implementation and end-to-end evaluation; ML venues expect benchmarks with statistical care.
4. Check whether the venue offers artifact evaluation (many systems venues do), and plan for it from the start.
